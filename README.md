# Introducció a Visual Studio Code

Visual Studio Code (VS Code) és un editor de codi gratuït desenvolupat per Microsoft. Permet escriure i editar diferents llenguatges de programació, com **Java, HTML, CSS, JavaScript, Python**, etc.

# Funcions Clau

- **Autocompletat:** ajuda a escriure codi més ràpid i evita errors.

- **Integració amb Git:** permet gestionar versions del codi i fer commits, canvis i branques.

- **Terminal integrat:** permet executar ordres i programes sense sortir de VS Code.

- **Debugar:** permet executar el codi pas a pas i analitzar variables amb punts d'interrupció sense utilitzar un `console.log`.

- **Extensions:** permet afegir noves eines, suport per a llenguatges i temes visuals des d'un mercat integrat.

- **Comandaments:** ofereix un cercador ràpid utilitzant la combinació de tecles `Ctrl + Shift + P` per executar qualsevol funció o opció de l'editor des del teclat.

- **Cerca i navegació avançada:** permet cercar i canviar text a tot el projecte o saltar a la definició d'una funció a l'instant.

- **Personalització d'entorns:** permet ajustar temes, dreceres de teclat i regles de formatat per a un usuari o projecte concret.

- **Desenvolupament remot:** permet programar directament dins de contenidors Docker, servidors per SSH o entorns al núvol com si fossin locals.
