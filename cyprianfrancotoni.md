# Que són les extensions?

Són eines que afegeixen funcionalitats específiques per a editors de text, aplicacions, navegadors... Un exemple seria que en
el navegador et pots instal·lar-te una extensió per fer captures d'imatges i extreure-li el text.

# Com instal·lar una extensió al Visual Studio Code?

Pasos a seguir:

1. Obrir l'aplicació Visual Studio Code.
2. En la part esquerra de l'aplicació cliques la icona d'un quadrat amb quatre quadrats dins.
3. Tens un navegador per buscar l'extensió que tu vols, si no et suggereix unes.
4. Cliques en l'extensió a instal·lar i prems el botó d'instal·lar.

# Exemples d'extensions VSCode

1. Prettier: Permet donar-li format al codi cada cop que guardem els canvis.

2. Error Lens: Permet visualitzar els errors en cada línia de cada arxiu.

3. Live Server: Aquesta extensió permet llançar un servidor local on visualitzarem els nostres arxius en temps real. ex(HTML)

4. Docker: Permet gestionar imatges, contenidors,volums, xarxes des de la pròpia aplicació.

5. CodeSnap: Et permet fer captures boniques del codi.

6. Rainbow Brackets: serveix per identificar cada parèntesis, claudàtor o clau amb un color diferent perquè
   sigui més fàcil identificar-los.
