# ** História dels navegadors i la seva arquitectura **


 ## 1.Explicació de l'arquitectura web:

 ### * 1.1 Com es comuniquen entre ells: *

La interacció entre el client i el servidor s’anomena model-client. El client bàsicament és un dispositiu que s’encarrega de fer peticions a un servidor. Aquestes peticions normalment demanen, pujant, actualitzen o esborren, normalment aquestes peticions són amb metodes http. El servidor finalment rebre aquestes peticions i tornarà una informació depenen dels mètodes seleccionats(Post, Get, PUt, Delate)


### ** 1.2 Diferencia: **

La diferència entre el servidor i el client es basa principalment amb que el client s’encarrega de fer les peticions al servidor i processar la resposta, mentre que el servidor és el que rep i envia la resposta corresponent basada amb les funcions definidas amb aquest.
